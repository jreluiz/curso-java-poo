# 🔗 Links Úteis — Java e POO

## 📖 Referência (para consultar, não para ler de capa a capa)

- [Documentação da API Java 21](https://docs.oracle.com/en/java/javase/21/docs/api/index.html) — **a** fonte oficial sobre `String`, `ArrayList`, `Files`... Aprenda a ler: classe → método → parâmetros → retorno → exceções lançadas;
- [Java Tutorials da Oracle](https://dev.java/learn/) — tutorial oficial, organizado por tema;
- [DevDocs — Java](https://devdocs.io/openjdk/) — a mesma documentação, com busca muito mais rápida;
- [Java: Guia do Programador (referência em pt-BR)](https://www.devmedia.com.br/guia/java/38109) — material introdutório em português para revisar conceitos.

## 🎮 Prática interativa

- [Exercism — trilha Java](https://exercism.org/tracks/java) — exercícios com mentoria da comunidade (excelente para praticar modelagem);
- [Codewars](https://www.codewars.com/) — desafios curtos por nível (comece pelos 8 kyu);
- [HackerRank — Java](https://www.hackerrank.com/domains/java) — trilha com exercícios de POO específicos;
- [JDoodle](https://www.jdoodle.com/online-java-compiler/) — compilador online, útil para testar um trecho rápido no celular ou num PC sem JDK.

## 🎨 Estilo e boas práticas

- [Google Java Style Guide](https://google.github.io/styleguide/javaguide.html) — a convenção mais usada do mercado (nomes, indentação, chaves);
- [Refactoring Guru — Padrões de Projeto (pt-BR)](https://refactoring.guru/pt-br/design-patterns) — o passo seguinte quando os quatro pilares ficarem naturais.

## 📐 Diagramas de classes

- [Mermaid — Class Diagram](https://mermaid.js.org/syntax/classDiagram.html) — desenha diagrama **dentro do README**, e o GitHub renderiza sozinho (é o que usamos no curso);
- [PlantUML online](https://www.plantuml.com/plantuml/uml/) — alternativa, exporta imagem;
- [Guia rápido do curso](diagrama-de-classes.md).

- [Eclipse Temurin (JDK)](https://adoptium.net/) — download do JDK;
- [IntelliJ IDEA Community](https://www.jetbrains.com/idea/download/) — IDE oficial do curso;
- [JUnit 5](https://junit.org/junit5/docs/current/user-guide/) — testes automatizados (degustação na Aula 16).
